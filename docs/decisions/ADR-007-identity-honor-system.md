# ADR-007: Name + emoji identity on the honor system

Status: Accepted
Date: 2026-11-08

## Context
The phone passes between friends constantly. Any sign-in step slows play, and the stakes are low.

## Decision
Players identify themselves by tapping their name + emoji (FR-101, FR-201). There are no passwords or PINs. The game trusts players not to play as each other.

## Consequences
- Fastest possible hand-off.
- Someone could answer as another player. Acceptable for a casual party game; a PIN option could be added later if needed.
